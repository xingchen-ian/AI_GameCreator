# 周六下午的数学小测 · 原型

纯静态网页：没有依赖、不用构建、不需要任何密钥。

## 启动

```bash
python3 -m http.server 8642
```

然后打开 http://localhost:8642 。直接双击 `index.html` 也能玩。

文件：`index.html`（结构）、`style.css`（样式）、`game.js`（全部规则）。

| 操作 | 鼠标 / 触控 | 键盘 |

## 已实现

- **四个状态**：开始页（规则 + 时长选择）→ 游玩 → 结算（铃响或主动交卷）→ 再考一次 / 返回开始。
- **试卷**：10 道选择题，每题 5 分；4 道大题，分别 11/12/13/14 分；满分 100。每局随机生成。
- **选择题 = 色块匹配**：从 4 个色块里找出和题干一样的。想清楚的程度越低，选项的色相/明度偏差越大、饱和度越低；信心越低，颜色闪得越厉害。难度越高，干扰项和正确答案越接近。
- **大题 = 逻辑链**：给一串符号（形状和颜色各自有周期规律），一步一步推出后面 3–5 项，每步三选一。候选项一开始是模糊的灰色，想得越久越清楚。每一步都对才得分。
- **解题两种模式**：按住 = 稳健，速度正常，信心会慢慢升到约 0.88；连点 = 激进，平均快约 1.7 倍，但每一下都有概率「思路乱了」，当前进度回退 20–45%，信心 −0.2，感觉难度变高。
- **投入产出不可预测**：每道题的实际耗时乘一个随机倍数（0.6–2.2）；难题有 25% 概率再 ×1.5（「坑题」）。中等和难题在解的过程中可能「灵光一现」，当前这一步直接完成。
- **读题**：首次进入一道题会自动读题，读完才给出「感觉难度」。这个标签带噪声，做到一半时会再修正一次。
- **改答案**：没验算锁定的答案随时可以改。选择题直接换一个选项，或者擦掉；大题点链上任意一步，从那一步起擦掉重推。改过的答案会重新判定有没有粗心。已验算锁定的不能改。
- **验算**：按住进行，耗时约为解题时间的 25–35%。笔误有 80% 能被发现并改正；选错 / 推错有一定概率被发现，发现后答案作废、进度回退。没发现问题就锁定（✓ 已验算），但锁定的答案仍可能是错的。
- **跳过**：会留下注意力残留，接下来约 0.6 分钟解题速度最多减半，屏幕边缘起雾。跳过的题思路丢 20%，回来要重读，重读有 25% 概率「换个角度就通了」，耗时 ×0.65（每题限一次）。
- **粗心**：作答时按 (1−信心)×22% 的概率记一个看不见的笔误，最后 5 分钟再加 5%。
- **反馈**：进度条的颜色（红→青）、透明度和抖动都跟着信心值变。系统从不告诉你对错，答题卡上只显示状态。顶部的「心里估分」是按信心算出来的自我感觉，不是真实分数。
- **看表**：时间平时不显示，点一次显示 2.5 秒，代价是打断当前操作并留下一点注意力残留。监考老师会在剩 30/15/5 分钟时报时。窗外光线随时间慢慢变暖，给一个模糊的时间感。
- **最后 5 分钟**：读题慢 60%，所有感觉难度上调，看东西更模糊，干扰更频繁，激进失手率上升，屏幕边缘泛红跳动。
- **外部干扰**：咳嗽（短暂没法操作）、老师站到身后（看得更模糊）、笔没水（暂时没法作答）、施工（变慢）、有人提前交卷（感觉更难）、风吹卷子。平时 5–9 分钟一次，最后 5 分钟 1.5–3 分钟一次。
- **结算**：总分、等级（<60 不及格 / 60 及格 / 75 良好 / 90 优秀）、复盘（估分和实际的差距、沉没成本最大的题、验算过仍然错的题、没来得及看的简单题、看表/切题/失手次数、事后看最划算的几道题），以及逐题讲评（你觉得的难度 vs 实际难度、用时、结果）。

## 设计假设

1. **时间压缩**：游戏内固定 60 分钟，现实时长可以选 3 / 6 / 60 分钟，默认 6 分钟（1 游戏分钟 = 6 秒）。
2. 「已确认作答」= 写了答案（不管验算没有）；答对才得分。验算的作用是降低错误率并锁定答案，**不是**计分的前提。
3. 「信心值」是每道题各自的数值，反映在进度条和画面清晰度上，也影响粗心概率。
4. 色块匹配和逻辑链本身需要玩家真的去观察、推理（保持智力参与）；进度条代表「想清楚的程度」，决定玩家能看多清楚。没想清楚也可以先蒙一个。
5. 大题全对才得分（GDD 写的是「仅累加已确认作答题目分值」），没有步骤分。
6. 「激进模式易致进度回退」做成每一下点击的失败概率，而不是一次性判定。
7. 跳过后回来要重读（GDD 原文），我额外加了「思路丢 20%」。
8. 等级阈值是我定的（GDD 只举了「不及格」「优秀」两个例子）。

## 与 GDD 的偏差（请确认）

- **「优先级队列」没有显示给玩家。** GDD 说系统会根据时间、分值、风险生成优先级队列，但如果直接显示出来，就等于替玩家做了「先做哪题」这个核心决策。所以只在结算时给出事后看最划算的题；游玩中玩家可以把题「圈起来」，自己排顺序。*最小修改*：如果要显示，可以做成一个只在最后 5 分钟出现、带噪声的「直觉提示」。
- **「回顾时可能触发新思路分支」** 做成了耗时减少（×0.65），没有真的生成一条新的解法路径。
- 「信心值波动」没有单独的数字显示，只能从画面上看出来，这是按 GDD「不直接告知」的思路做的。

## 建议试玩时问的问题

1. 你是什么时候决定放弃某一道题的？当时依据的是什么——时间、感觉难度、已经投入的时间，还是别的？
2. 你多久看一次表？看表那一刻是什么感受？有没有觉得「不知道时间」比「时间不够」更难受？
3. 连点（激进）和按住（稳健），你什么时候用哪个？最后 5 分钟有变化吗？
4. 验算让你觉得踏实，还是觉得浪费时间？看到「验算后仍错」时是什么反应？
5. 结算时，哪一条复盘让你最遗憾？你下一局会改变策略吗？
6. 进度条的颜色、抖动，你能看出自己「有没有把握」吗？
7. 外部干扰是让你更紧张，还是只是觉得烦？
8. 色块和符号规律这两种题，哪一种更像「做数学题」的感觉？
